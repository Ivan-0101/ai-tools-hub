# AI Tools Hub — демо прототип

Лека, статична уеб платформа на български за споделяне на AI инструменти.

## Стартиране

1. Разархивирай проекта.
2. Отвори `index.html` в модерен браузър.

Не са нужни инсталация, сървър или API ключове.

## Функции в прототипа

* Търсене по име, описание и тагове
* Филтри по екип/категория
* Добавяне на инструмент чрез форма
* Запазване на инструменти и гласуване за полезност
* Списък с топ препоръки
* Отваряне на официалния линк на инструмента
